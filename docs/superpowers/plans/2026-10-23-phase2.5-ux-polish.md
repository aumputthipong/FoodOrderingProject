# Phase 2.5 UX Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** เกลา UX/UI ของ `apps/web` ตามผลตรวจ top 10 และ follow-ups ที่เกี่ยวข้อง โดยไม่เปลี่ยนฟีเจอร์และไม่แก้ API

**Architecture:**
- **พื้นฐานก่อน:** ทำ token, primitive, ข้อความ validation และ empty/error state ก่อน ทุกหน้าจะได้ผลไปด้วย
- **แล้วค่อยเกลาทีละกลุ่มหน้า:** ใช้ component และ pattern เดิมของ phase 2 (feature folders, props/emit, query ใน `queries.ts`)
- **Motion:** ใช้ได้เฉพาะ CSS transition ของสีและความกว้างแถบ

**Tech Stack:** เหมือน phase 2 คือ Vue 3.5, Tailwind 4 (`@theme`), shadcn-vue/reka-ui, `@lucide/vue`, vue-sonner, `@vueuse/core`, Vitest + Vue Test Utils + MSW

**Spec:** `docs/superpowers/specs/2026-10-23-phase2.5-ux-polish-design.md` (รหัสอย่าง GLOB-6 อ้างถึงผลตรวจ ข้อความไทยทั้งหมดอยู่ใน spec ให้ใช้ตามนั้นทุกตัวอักษร)

## Global Constraints

- **Branch:** `feat/ux-polish` ใช้ Conventional Commits และ **ห้าม push**
- **ทุกคำสั่ง shell:** ขึ้นต้นด้วย `export PATH="/c/Users/aumptp/AppData/Roaming/fnm/node-versions/v24.22.1/installation:$PATH" && `
- **ห้ามแตะ:** `apps/api/**` และ `packages/shared/**`
- **ห้ามเพิ่ม dependency:** ใช้เฉพาะของที่ติดตั้งแล้ว (`useNow` มาจาก `@vueuse/core`)
- **Motion:**
  - ใช้ได้: `transition-colors`, สีเข้มขึ้นตอน `active:`, `motion-safe:transition-[width]` ของแถบความคืบหน้า, animation มาตรฐานของ vue-sonner/reka-ui, `animate-spin` ของ `Loader2`
  - ห้าม: `<Transition>`, `<TransitionGroup>`, `animate-in`, fade/slide/zoom ตอนปรากฏ, `scale` ตอนกด
- **Token ใหม่** (`@theme` ใน `main.css`):
  - ตัวอักษร: `--text-caption: 13px`, `--text-body-sm: 15px`, `--text-title: 20px`, `--text-display: 26px`, `--text-ticket: 44px`
  - ความโค้ง: `--radius-card: 16px`, `--radius-thumb: 10px`
  - ได้ class `text-caption`, `rounded-card`, `text-ticket` และอื่นๆ ตามชื่อ
- **ในไฟล์ที่แตะ:** ห้าม `text-[NNpx]` และ `rounded-[NNpx]` ที่มี token รองรับ, ห้าม `stone-*`, `rgba(`
- **Contrast:** ตัวอักษร ≥ 4.5:1, focus ring และ control ≥ 3:1 บนพื้น `#FFFFFF`, `#F5F5F4` และ `#C2410C`
- **ห้ามใช้ `v-html`:** ห้าม `any` และใช้ Prettier ตาม `.prettierrc`
- **ก่อน commit ทุก task:** `pnpm lint && pnpm typecheck` ที่ root, `pnpm --filter @canteen/web exec vitest run` และ `pnpm exec prettier --check apps/web` ต้องผ่าน

## Review Focus

1. **เวลา `createdAt` อยู่ในอนาคต** (นาฬิกาเครื่อง client ช้ากว่า server) ต้องแสดง 'เพิ่งสั่ง' ห้ามแสดงนาทีติดลบ (test อยู่ใน Task 2)
2. **ช่องค้นหากับ URL ต้องไม่วนกัน:** การ sync ช่องค้นหากับ `?q=` เวลากด back/forward ห้ามทำให้ `router.replace` วนไม่จบ และห้ามล้างสิ่งที่ผู้ใช้กำลังพิมพ์ (test อยู่ใน Task 4)
3. **กด 'ย้อนกลับ' ใน toast แล้ว mutation ล้มเหลว:** หรือออเดอร์ถูกเปิดกลับไปแล้ว ต้องแสดง toast error ไม่ crash และไม่ทิ้งปุ่มค้างสถานะ busy (test อยู่ใน Task 8)
4. **`formatMobile` ได้ค่าแปลก:** ว่าง, ไม่ใช่ 10 หลัก หรือมีตัวอักษร ต้องคืนค่าเดิม (test อยู่ใน Task 2)
5. **Focus ring บนปุ่มส้มและป้าย 'หมดชั่วคราว':** ต้องมองเห็นได้ บันทึก contrast ที่คำนวณได้ในรายงาน (Task 1, Task 5)
